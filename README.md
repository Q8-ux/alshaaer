# أنت الشاعر

تطبيق عربي يحوّل القصة المكتوبة أو التسجيل الصوتي إلى أبيات شعرية مخصّصة. يحلل الذكاء الاصطناعي القصة أولًا، ثم يستوضح المطلوب ويكتب القصيدة، مع أرشفة المحتوى ولوحة إدارة.

## المزايا

- كتابة القصة أو تسجيلها صوتيًا
- تحليل القصة وصياغة أبيات شعرية مخصّصة
- خطوات إنشاء واضحة تحفظ تسلسل القصة والتحليل والاختيارات والقصيدة
- حفظ مسودة محلية واستعادتها تلقائيًا بعد الانقطاع
- أرشيف للقصص والتسجيلات والقصائد
- مركز بيانات محمي على `/control-center` يجمع القصائد والأوصاف والتفريغ والملفات الصوتية
- واجهة عربية بخط المهند
- تهيئة للنشر عبر Cloudflare Workers وD1 وR2
- نقطة فحص تشغيلية على `/api/health`

## التشغيل محليًا

```bash
npm ci
npm run dev
```

## النشر

لا يصلح GitHub Pages لتشغيل التطبيق الكامل، لأن الذكاء الاصطناعي والأرشيف والصوت والحسابات تحتاج خادمًا وقاعدة بيانات وتخزينًا آمنًا.

يتضمن المشروع إعداد نشر إلى Cloudflare. راجع ملف `CLOUDFLARE_DEPLOYMENT.md` قبل تفعيل GitHub Actions.

توجد بوابة تعريفية ثابتة على GitHub Pages، أما التطبيق الكامل فيحتاج بيئة Cloudflare الموصوفة أعلاه.

## الجودة والتشغيل

يوثّق [دليل الجودة والتشغيل](docs/quality-and-operations.md) نطاق المنتج، وتدفقات الاستخدام، وضوابط القبول، والفحوص السابقة للنشر.
وتحدّد [خريطة موارد المشروع](docs/project-resources.md) المستودع وموارد Cloudflare الخاصة بالخدمة.

## الأمان

لا تضع مفاتيح OpenAI أو كلمات المرور أو رموز Twilio في الكود أو GitHub. تُضاف فقط كمتغيرات سرية في بيئة التشغيل.
