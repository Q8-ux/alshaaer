# موارد أنت الشاعر

يخص هذا المستودع مشروع «أنت الشاعر» فقط. لا تُضاف إليه شفرة أو أصول تخص ألعابًا أو خدمات أخرى.

| المورد | المعرّف الرسمي | المسؤولية |
| --- | --- | --- |
| GitHub | `Q8-ux/alshaaer` | الشفرة والاختبارات وإجراءات النشر |
| GitHub Pages | `q8-ux.github.io/alshaaer` | البوابة التعريفية الثابتة |
| Cloudflare Worker | `ant-alshaer` | التطبيق الكامل ومسارات API |
| Cloudflare D1 | `ant-alshaer-db` | الحسابات والقصص والقصائد والأرشيف |
| Cloudflare R2 | `ant-alshaer-audio` | التسجيلات الصوتية |

## حدود الملكية

- تُحفظ أسرار OpenAI وCloudflare وTwilio في بيئات التشغيل فقط.
- لا يشارك المشروع مستودعًا أو قاعدة بيانات أو خدمة نشر مع AI Chess Kuwait.
- لا تُفعّل عملية Cloudflare إلا بعد ربط D1 وR2 وضبط الأسرار الخاصة بهذا المشروع.
- تبقى GitHub Pages بوابة تعريفية، ولا تُعامل على أنها بديل للتطبيق الكامل.
